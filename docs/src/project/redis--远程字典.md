# redis与远程字典

![](https://imgstroe-redblacktree.oss-accelerate.aliyuncs.com/img/20260319065019938.png)

mysql是个典型的sql数据库，通过表创建关系，保持在磁盘中，支持jion等复杂操作。但在现在高并发的时期，mysql涉及磁盘操作，难以应对并发，mysql适合单机，难以解决分布式，因此nosql数据库被提出，redis 是一个典型的nosql数据库

- 键值对的形式而非表，存储类型简单，不支持复杂查询，以换取更高的速度
- 工作时存储在内存而非磁盘，实现快速读取写入

- 单例模式避免线程切换带来的开销
  - 虽然是单例模式，但通过io多路复用可以实现一对多连接，底层是结合中断实现 


redis 全称为 Remote Dictionary Server ，远程字典服务，名字已经很好概况了

## 持久化如何保证

redis既然都是加载到内存中，那么比如突然断电如何保证数据不丢失

1. RDB 快照，每隔5分钟将内存数据更新到外存中
   (采用写时复制，主和从都是通过共享内存，只有当主修改时，复制一页新给主，而从仍然用旧的)
2. AOF ，记录每一条写命令到磁盘中，类似于英雄联盟回放是通过记录玩家游戏操作
   （顺序写因为有缓冲区的存在，写入速度会非常快）
